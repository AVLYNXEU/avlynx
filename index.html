Keyboard shortcuts

Ctrl + Z / YUndo / redo
Ctrl + SSave the project in this browser
Ctrl + ASelect everything on this sheet
Ctrl + C / X / VCopy, cut, paste the selection, also into another sheet or project
Ctrl + DDuplicate the selection
Shift + clickAdd an object to the selection, or remove it
Shift + dragSelect everything inside a frame; a frame across lines only selects those lines. With Ctrl as well, add to the selection
Right-click, long pressMenu with the actions for the object, or for an empty place
Double-click a sheet tabRename the sheet
Middle mouse button + dragMove the view, also when the pointer is on a device
Arrow keysMove the selection by one grid step; with Shift by one pixel
DeleteDelete the selection
Double-clickEdit a device or a text
+ / − / FZoom in / out / show the whole drawing
EscCancel, clear the selection

On a Mac, use ⌘ instead of Ctrl. Hold Alt while moving to switch the alignment guides off for that move.
